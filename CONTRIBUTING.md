# Contributing

Issues and pull requests are welcome. Keep changes focused and include reproduction steps for bug fixes or a short explanation for behavior changes.

Before opening a pull request, follow the source setup in the [README](README.md) and run `.\build.ps1` from the repository root. This runs the production build and the project’s existing UI and native checks.

Contributions intended for inclusion in Setpiece must be offered under the project’s [PolyForm Noncommercial License 1.0.0](LICENSE). By submitting a pull request, you confirm you have the rights needed to make that contribution available under those terms. The project does not require a copyright assignment or separate contributor license agreement.

Do not include credentials, personal data, private browser state, or generated build artifacts in a contribution. Third-party code or assets must be identified with their source and license so their notices can be preserved.
