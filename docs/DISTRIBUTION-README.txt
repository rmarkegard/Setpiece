Setpiece 2.0.0 — Windows x64

REQUIREMENTS
- Windows 11 x64
- .NET 10 Desktop Runtime x64
- Microsoft Edge WebView2 Evergreen Runtime

Setpiece is framework-dependent. Install both runtimes above before launching.

RUN
Keep the extracted Setpiece folder and its contents together. Start Setpiece.exe.
Normal profile and connection data is stored under %APPDATA%\Setpiece.
