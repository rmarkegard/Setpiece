# Screenshots

Captured from the development preview (`?mock=1`), which runs the real Setpiece interface against sample data, rendered in Chromium like the app. Every shot uses the default look of the 2.0.2 site: Glass surfaces, the Plain palette and the Mercury flow wallpaper (`surface=glass&palette=plain&wallpaper=mercury-flow`). Clocks are pinned to 10:24 with `mockTime`. Connected states are sample data, not signed-in services.

- `dark-*.png`, `light-*.png`: the Studio, Widgets, widget setup dialog, Browsers, Appearance and Settings pages.
- `accent-*.png`: Studio in the Sage, Ocean and Rose accents.
- `widgets/`: each widget as its own window over the wallpaper, corners clear, in both modes.
- `demo/`: the toolbar and three widgets captured at their exact tile sizes on a 1920 × 1080 display, used by the fullscreen demo.
- `fullscreen/`: the project page's demo in three states: tiled, fullscreen inside the tile, and ordinary fullscreen.

See "Project page" in the repository README for the preview parameters.
