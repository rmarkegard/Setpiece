# Native WebView2 screenshots

These images were captured on the current Windows Release build from the native WebView2 host. The capture ran with a new isolated data root, `--offline-review`, and an exact route filter. The review excluded Apps, made no public weather/transit requests, and used a profile named Setpiece Reveal. Empty connection states are real; they are not presented as signed-in services.

The two Widget library images were refreshed after the catalog action buttons were adjusted to stay on one line. The other screens are from the preceding successful full review capture.
